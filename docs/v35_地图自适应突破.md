# v35 真正的地图动态应对成功

## 失败重启

之前两次试地图自适应都失败：
- **v31**：换 SIM_HORIZON / K → 中性（43% ≈ v20 的 47%）
- **v33**：v32 + SIM_HORIZON / K 自适应 → **崩盘 12%**
- **v34**：v32 + SIM_HORIZON / K / shot_threshold 全切 → **20%**

**关键洞察**：我 v20 的 (h=16, K=15) 是参数搜索调出来的局部最优。**动 sim 参数就破坏这个最优**。

## v35 思路

**只切 shot threshold**，保留 v20 调好的 sim 参数：

```python
if angular_velocity < 0.035:  # slow rot
    shot_threshold = 0.20      # loose: 几乎不过滤，让 v20 sim 自由
else:                          # fast rot
    shot_threshold = 0.40      # tight: 像 v32，专克 mlhybrid
```

- SIM_HORIZON 恒为 16（v20 调好的）
- K 恒为 15（v20 调好的）
- 只是不同 rotation 用不同 shot filter 严厉度

## Benchmark（5 seeds × 5 强对手 = 50 局）

| 对手 | v20 | v32 (shot t=0.40) | **v35 (adapt thresh)** |
|---|---|---|---|
| mlhybrid | 0% | **30%** | **30%** ✓ |
| orbitbotnext | 20% | **40%** | 20% |
| proto1000 | 30% | 20% | 20% |
| structured | 50% | 30% | **50%** ✓ |
| lb1224 | 60% | 50% | **60%** ✓ |
| **总** | 32% | 34% | **36%** ⭐ |
| vs 弱对手（random/starter/v2d） | 100% | 100% | **100%** ✓ |

**v35 是最稳的**：
- 保留 v20 的强项（lb1224 60%, structured 50%）
- 保留 v32 的关键 fix（mlhybrid 0→30%）
- vs 弱对手 100% 不退化

## 为什么这次行了

慢转地图（约 1/3 概率）→ threshold 0.20 → 几乎所有候选都通过 shot filter → **agent 行为接近 v20**：
- 在 lb1224 类对手（深 sim 派）上 v20 本来就 60%，保住
- 在 structured 上 v20 是 50%，保住

快转地图（约 2/3 概率）→ threshold 0.40 → 过滤掉低概率发射 → **agent 行为接近 v32**：
- 在 mlhybrid 类对手（shot reject 派）上 v32 是 30%，保住

两个模式各管自己强项的地图类，**互不打架**。

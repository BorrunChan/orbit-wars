## 五、唯一未失败方向：v114 Ensemble

### 设计

```python
# v114 pseudocode
import v98_logic, v110_logic
_state = {"opp_launches_total": 0, "decision": None}

def agent(obs):
    step = obs.step
    n_opp_fleets = count_enemy_fleets(obs)
    _state["opp_launches_total"] = max(_state["opp_launches_total"], n_opp_fleets)
    
    # Sticky decision after step 20
    if _state["decision"] is None and step >= 20:
        avg_lr = _state["opp_launches_total"] / max(1, step)
        _state["decision"] = "v110" if avg_lr > 5 else "v98"
    
    if _state["decision"] == "v110":
        return v110_logic.agent(obs)
    return v98_logic.agent(obs)
```

### 风险

- launch_rate 估算粗（只看 in-flight，不算 retired）
- 切换决策"卡死"（无回退机制）
- 文件 ~1500 行（v98 全 + v110 全 + router）

### 实现工程量

- ~2-4 小时编码
- 1 bench v114 vs standard 5 opps + proto1000 = 6 opps
- 期望：standard ≥ v98（47%），proto1000 ≥ v110 (vs v98 100%)

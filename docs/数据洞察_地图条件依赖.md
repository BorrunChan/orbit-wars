330 局 round-robin 数据（11 个 agent 互打 × 3 seeds）揭示了**没有通用最强**——agent 强度高度依赖地图旋转速度。

## 按地图旋转速度切割

每张地图的 `angular_velocity` 在 0.025-0.05 之间均匀分布。这次 330 局里 slow_rot (< 0.035) 占 33%，fast_rot (> 0.045) 占 67%。

### Slow rotation (<0.035 rad/turn, 110 games)

| Agent | 胜率 |
|---|---|
| **lb1224** | **80%** |
| **orbitbotnext** | **80%** |
| sundodge | 75% |
| structured | 65% |
| peak1103 | 60% |
| mlhybrid | 60% |
| **main (v20)** | **55%** |

慢转情况下，**深 sim + 精确旋转预测**派（lb1224 / orbitbotnext）大杀四方。它们能精准预测内圈行星位置，集中精力抢高产。

### Fast rotation (>0.045 rad/turn, 220 games)

| Agent | 胜率 |
|---|---|
| **mlhybrid** | **78%** |
| search_lvf | 60% |
| proto1000 | 60% |
| structured | 55% |
| sundodge | 55% |
| **main (v20)** | **55%** |
| orbitbotnext | 52% |
| **lb1224** | **50%** |

**注意 lb1224 从 80% 暴跌到 50%。** 快转情况下，深 sim 预测的位置随时间误差快速放大，反而成为累赘。**mlhybrid 的"ML reject 拒绝坏发射"策略在快转下最稳**——它不预测精确位置，只拒绝注定打不到的发射。

## 这告诉我们什么

### 1. 没有"通用最强"

| Agent | slow_rot WR | fast_rot WR | 差 |
|---|---|---|---|
| lb1224 | 80% | **50%** | **-30** |
| mlhybrid | 60% | **78%** | **+18** |
| orbitbotnext | 80% | 52% | -28 |
| structured | 65% | 55% | -10 |
| **main (v20)** | **55%** | **55%** | **0**（稳定）|

v20 是**两类地图都 55% 的中庸派**——这正是参数搜索（grid-based）的特征：在 fixed seeds 上调出来的参数对所有 seed 类型平均最优，不针对特定地图。

### 2. 真正的提升方向

地图自适应策略切换：

```python
av = obs.get("angular_velocity", 0)
if av < 0.035:
    # 慢转 → 深 sim 派
    horizon = 20+
    K = 30
    # ...
else:
    # 快转 → 防御保守派
    horizon = 8
    K = 15
    # 优先 ML reject style: 高门槛拒绝低质量发射
```

如果实现得好：
- 慢转用 lb1224 路线 → 期望 75-80% 区间
- 快转用 mlhybrid 路线 → 期望 70-78% 区间
- **总体 75%+ 是有可能的**（vs 当前 v20 的 55%）

但这要求**真正实现两套策略**，不是简单调参。工程量大概 1-2 天。

### 3. 单局变量解释

之前看到 bowwowforeach vs Ebi 同样代码两局结果相反，地图差异是 seed=959919717 (angular_velocity=0.0489，快转) vs seed=1281654089 (0.0353，慢转)。

**Ebi（lb1224 风格）在快转地图反而吃亏**——这跟数据完全吻合。

bowwowforeach 看起来是更接近 mlhybrid 的鲁棒派，所以在快转地图能 116 步速胜。
